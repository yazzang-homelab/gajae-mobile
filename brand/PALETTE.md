# gjc-mobile 대표 색상 (가재코드 GitHub 이미지 실측)

출처: `Yeachan-Heo/gajae-code` `assets/hero.png`, `assets/logo-vertical.png`, `assets/telegram-mobile-hero.png`.
추출: 영역별 조건 픽셀 최빈값(`hero.png` 1672x941 원본 좌표). 재현 스크립트는 이 문서의 표 근거를 그대로 쓴다.

| 토큰 | HEX | 근거 영역 | 용도 |
|---|---|---|---|
| `gajaeRed` (primary) | `#EA4523` | 워드마크 "gajae", 목록 불릿(`#E94321`), 로고 갑각 주색(`#F73901`/`#CA1701`) | 주 액센트, 전송 버튼, 선택 상태, 사용자 말풍선 |
| `strawGold` | `#ED9324` | 밀짚모자, 로고 복부(`#E37711`) | 보조 액센트, 실행 중·대기 상태, 경고 |
| `visorGreen` | `#25DF87` | 고글 눈, 태그라인 "Encode/Decode" | 성공·온라인·승인, 커서 |
| `cream` | `#F7E7D1` | 워드마크 "-code" | 본문 전경 텍스트 |
| `ink` (background) | `#0A0707` | 히어로 배경 | 앱 배경(다크 고정) |
| `shell` | `#1A1110` | 배경과 `#2B1411`(갑각 그림자) 사이 보간 | 카드·말풍선 배경 |
| `shellLine` | `#3A2420` | 히어로 구분선 계열(적갈) | 구분선·테두리 |
| `muted` | `#A8968A` | cream 대비 60% | 보조 텍스트·타임스탬프 |

판단: 세 이미지 모두 거의 검은 배경 위에 가재의 주홍(red-orange)이 면적·채도 모두 지배적이고, 녹색 고글과 금색 모자가 소면적 포인트다. 웹사이트 배지 `#ff4d4f`도 같은 적색 계열이다. 따라서 다크 테마 고정 + 주홍 primary + 녹색 상태색 + 금색 보조색으로 정한다. `telegram-mobile-hero.png`의 청색 UI는 텔레그램 클라이언트 색이므로 브랜드 색에서 제외한다.

워드마크·UI 글꼴: 히어로가 픽셀/모노스페이스 타이포를 쓰므로 코드·도구 출력은 `.monospaced`, 본문은 시스템 글꼴로 둔다.
