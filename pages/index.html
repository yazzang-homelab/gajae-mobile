Gajae Code mobile · 가재코드 모바일

Your agent asks. Your phone answers. A companion app for Gajae Code (gjc), the coding agent that runs on your own computer: start work, approve the commands it wants to run, steer a running turn, and see on your home screen which session is waiting for you.

Privacy Policy · 개인정보처리방침 · Source code (AGPL-3.0)

Getting started

  1. On your computer, install Bun and Gajae Code, then run the bridge from the repository: cd bridge && bun install && bun src/cli.ts serve --gjc "gjc --mode=acp"
  2. Run bun src/cli.ts pair and scan the QR code with the app.
  3. No computer at hand? Tap 컴퓨터 없이 데모로 체험 (try the demo without a computer) on the first screen; the demo host returns scripted replies and runs nothing.

시작하기

  1. 컴퓨터에 Bun과 가재코드를 설치하고 저장소의 브리지를 실행합니다: cd bridge && bun install && bun src/cli.ts serve --gjc "gjc --mode=acp"
  2. bun src/cli.ts pair로 나온 QR 코드를 앱에서 스캔합니다.
  3. 컴퓨터가 없으면 첫 화면의 컴퓨터 없이 데모로 체험을 누릅니다. 데모 호스트는 정해진 응답만 돌려주고 아무것도 실행하지 않습니다.

Help · 문의

Questions, bugs and feature requests: GitHub issues. Lost a phone? Run bun src/cli.ts revoke <name> on the host to cut it off immediately.

질문·버그·기능 요청은 GitHub 이슈로 남겨 주세요. 휴대폰을 잃어버리면 호스트에서 bun src/cli.ts revoke <이름>으로 즉시 끊을 수 있습니다.
